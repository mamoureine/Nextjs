# Marieme SALL — Portfolio

A responsive personal portfolio built with Next.js, TypeScript, and the App Router.
Each page is rendered by a server component, with file-based routes for Home,
About, Projects, and Contact.

## Get started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the website.

## Customize

- Replace the example project concepts and descriptions in `app/page.tsx` and
  `app/projects/page.tsx`.
- Replace the illustrated SVGs in `public/images/` with your own project and
  profile images.
- Update the sample email address on `app/contact/page.tsx` to your own.

## Build and deploy

Run `npm run build` to create a production build, then `npm start` to serve it.
The app can be deployed to any hosting platform that supports Next.js, including
Vercel.
